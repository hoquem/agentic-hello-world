Every engineer's first program is "Hello, World" — one line, same output every time. So what happens when you write it with an LLM instead? It turns out the rules change: you stop writing deterministic code and start writing prompts, where the behaviour depends on the model, the input, and chance.

In Episode 1 we build the simplest possible "AI program," then open up a transparent harness that shows the literal bytes sent to and received from the model — and prove, live, why the same prompt can give different answers.

This is Episode 1 of "Building an AI Agent from Zero" — a series that builds an agent one capability at a time. The big idea: an agent is a stateless LLM wrapped in a harness (the code you write). The model never changes; every new ability lives in the harness.
