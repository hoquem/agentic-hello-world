def run(self):
    # wrap the deck into a request (and show it)
    request = build_request(self.messages, self.model)
    yield {"type": "sent", "request": request}

    # stream the reply, keeping the text
    assembled = ""
    for chunk in self._chat_fn(request):
        content = chunk["message"]["content"]
        if content:
            assembled += content
        yield {"type": "received_chunk", "raw": chunk}

    # remember it, then display it
    self.messages.append({"role": "assistant", "content": assembled})
    yield {"type": "display", "content": assembled}
The model is stateless. Everything an "agent" does lives in code this simple — the harness, not the model.
